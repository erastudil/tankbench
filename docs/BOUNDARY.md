# Boundary

This tree is a defensive hardening bench. One hostile patient. One alive spec. One sealed round file. A harness that scores on localhost.

## In

- Harbor Ledger patient: spaghetti, lying comments, dead files, intern flaps
- synthetic roster (Bob Average, Jane Normal, Sally Representative Sample)
- alive tests that prove the shop still works and the roster does not appear
- judge-only rounds that exfiltrate that roster through those flaps
- harness, scoring, CLI
- the harden prompt

## Out

- OWASP replay as the point of the bench (known bug, known fix)
- generic exploit kits, payload packs, scanners
- attacks aimed at any host other than the local patient
- real shell-out, malware, or exploit development as a task
- real personal data, real SSNs, real phones
- training pipelines and model adapters
- field product code

A probe that would work unchanged against a stranger's app does not belong here. The flap has to be unique to this intern. Rewrite it until it is sealed, or delete it.

A round that is "run sqlmap" or "GET /notes/2" is the wrong sport.
